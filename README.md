# Tofes0

אתר Flask פשוט בפייתון, מוכן לפריסה ב-Render.

## הרצה מקומית

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

פתחו http://127.0.0.1:5000

## פריסה ב-Render

Render → New → Blueprint → בוחרים את המאגר הזה. ההגדרות נמצאות ב-`render.yaml`.
